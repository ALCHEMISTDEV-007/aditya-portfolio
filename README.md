# Aditya portfolio

A Next.js portfolio focused on creative software, AI, cybersecurity and systems. The hero uses an isolated stylized character illustration with restrained cursor parallax; it is artwork rather than a 3D model. The owl is a separate SVG companion animated along eased, changing screen positions.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```
